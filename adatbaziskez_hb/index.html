Tantárgy Áttekintése

Az Adatbáziskezelés tantárgy alatt a relaciós adatbázisok gyakorlati alkalmazását tanultuk meg. Kezdetben Microsoft Access-ben dolgoztunk az adatbázisok szerkezetén és tervezésén, majd áttértünk az SQL nyelvre, amelyet MySQL Workbench-ben gyakoroltunk.

Fő tanulási témakörök:

  • Microsoft Access - Adatbázis szerkezete, táblák, jellemzők
  • SQL alapok - SELECT, INSERT, UPDATE, DELETE műveletek
  • MySQL Workbench - Adatbázis környezet és SQL nyelv használata
  • Lekérdezések - JOIN, WHERE, ORDER BY, GROUP BY

Gyakorlatok és Kérdések

SQL műveletek:

  • SELECT - Táblákból adatok kiválasztása
  • WHERE - Feltételek alapján szűkítés
  • JOIN - Táblák összekötése relaciók alapján
  • INSERT, UPDATE, DELETE - Adatok módosítása
  • GROUP BY és aggregációk - Adatok összegzése (COUNT, SUM, AVG)
  • ORDER BY - Eredmények rendezése

Access gyakorlatok:

  • Adatbázis szerkezetének megtervezése
  • Táblák létrehozása és kapcsolatok definiálása
  • Egyszerű és bonyolult lekerdézések készítése
  • Jelentések generálása

MySQL Megvalósítás

Megtekintés: 

CREATE DATABASE roulette;
USE roulette;

CREATE TABLE jatekos (
    jatekos_id INT AUTO_INCREMENT PRIMARY KEY,
    nev VARCHAR(100) NOT NULL,
    szemelyi_szam VARCHAR(20) UNIQUE,
    regisztracio DATE
);

CREATE TABLE jatek (
    jatek_id INT AUTO_INCREMENT PRIMARY KEY,
    datum DATETIME,
    nyertes_szam INT,
    szin VARCHAR(10)
);

CREATE TABLE tet (
    tet_id INT AUTO_INCREMENT PRIMARY KEY,
    jatekos_id INT,
    jatek_id INT,
    tet_tipus VARCHAR(50),
    osszeg INT,
    nyeremeny INT,
    
    FOREIGN KEY (jatekos_id) REFERENCES jatekos(jatekos_id),
    FOREIGN KEY (jatek_id) REFERENCES jatek(jatek_id)
);

Játékos teljes profit lekérdezése

Megtekintés: 

SELECT 
    j.nev,
    SUM(t.nyeremeny - t.osszeg) AS profit
FROM tet t
JOIN jatekos j ON j.jatekos_id = t.jatekos_id
GROUP BY j.nev;

Legnagyobb nyeremény lekérdezése

Megtekintés: 

SELECT *
FROM tet
ORDER BY nyeremeny DESC
LIMIT 1;
